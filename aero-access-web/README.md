# Aero Access Web

Versão web independente, extraída dos assets usados pelo aplicativo Android.
O projeto Android original não é modificado por esta versão.

## Publicação na Netlify

- Diretório de publicação: `.`
- Comando de build: nenhum
- Página inicial: `index.html`

O arquivo `netlify.toml` já contém a configuração necessária para hospedagem estática.
